# 🚀 Quick Share Tile

Turn the Windows 11 Nearby sharing tile into a one-click Quick Share launcher. Keep your Quick Settings layout intact while giving that native tile a fresh, useful purpose. ✨

## Why this mod? 🤔

Windows 11 ships with a Nearby sharing tile that looks useful, but for many users it feels like dead space. Quick Share Tile gives that tile a smarter job: it launches Quick Share instantly with a single click. ⚡

No awkward extra clutter. No layout breakage. Just a polished upgrade to a familiar control. 💡

## Highlights ✨

- 🔁 Replaces the Nearby sharing Quick Settings tile
- 🚀 Launches Quick Share in one click
- 🎯 Keeps the native tile size, position, and styling
- 🛠️ Restores the original tile when the mod is disabled
- 🧩 Works as a lightweight Windhawk customization

## What it looks like 👀

Instead of a generic Nearby sharing tile, you get a Quick Share launcher that fits naturally into the Quick Settings experience. It preserves the original Windows design language while changing the behavior to something faster and more useful. 📱

## Requirements ✅

- Windows 11 x64
- Windhawk
- Quick Share installed
- Quick Share shortcut at:

  `C:\ProgramData\Microsoft\Windows\Start Menu\Quick Share.lnk`

## Installation 🧰

1. Install Windhawk.
2. Load the mod file.
3. Make sure Quick Share is installed and the shortcut exists.
4. Enjoy your upgraded Quick Settings tile. 🎉

## Settings ⚙️

### Native tile to replace
The accessibility name of the tile to take over.

Default: `Nearby sharing`

If your Windows language is not English, update the tile name accordingly. 🌍

### Log the visual tree
Enable debug logging to inspect the Quick Settings visual tree for troubleshooting. 🪵

## Known limitations ⚠️

- Tested on Windows 11 x64 build 26300
- Other Windows builds are not guaranteed to work
- The tile's active visual state still reflects Nearby sharing, not Quick Share's real status
- The shortcut path is currently hardcoded
- This mod launches Quick Share; it does not add Quick Share functionality itself

## Uninstall 🗑️

Disable or remove the mod from Windhawk. The original Nearby sharing tile is restored automatically, including its label, icon, click behavior, and keyboard navigation.
